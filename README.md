# Portfólio — Rafael Gomes

Site estático desenvolvido com HTML, CSS e JavaScript, pronto para GitHub Pages.

## Rodar localmente

Abra `index.html` no navegador ou execute na pasta do projeto:

```bash
python -m http.server 8000
```

Então visite http://localhost:8000.

## Publicação

1. Envie `index.html`, `style.css` e `script.js` para a raiz do repositório `FaellEmiliano.github.io`.
2. Em **Settings → Pages**, selecione **Deploy from a branch**, **main** e **/(root)**.
3. Acesse `https://faellemiliano.github.io`.

## Personalize antes de publicar

- Substitua o link genérico de LinkedIn na seção Contato.
- Revise a descrição dos projetos e a lista de tecnologias.
- Acrescente seu e-mail e currículo, caso queira disponibilizá-los.
- A arte dos projetos é ilustrativa, feita com CSS, e pode ser trocada por capturas reais.
